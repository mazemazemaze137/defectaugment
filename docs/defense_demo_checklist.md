# DefectAugment 答辩演示流程清单

## 1. 开场定位

- 说明问题：工业缺陷样本采集成本高、类别覆盖不足，单纯提高模型复杂度不能解决数据不足。
- 说明系统目标：构建从数据预处理、增强、评估、下游验证到工业门槛判断的闭环工具。
- 一句话结果：40 轮 cGAN-v2 每类 100 张生成样本方案在 3 随机种子复验中平均最佳准确率达到 99.44%，高于原始基线 98.15%。

## 2. Streamlit 演示顺序

1. 打开系统：`streamlit run src/app.py`
2. 先打开“答辩材料与健康检查”：确认关键路径、论文长度、复现清单、核心证据图和烟测状态。
3. 展示“数据管理/预处理”：说明 ROI 裁剪、CLAHE 对比度增强、中值滤波去噪。
4. 展示“传统增强”：说明传统增强是稳定基线，不回避其效果强。
5. 展示“GAN 训练/生成”：说明 cGAN-v2 使用 Projection Discriminator、Hinge Loss、DiffAugment 和 EMA。
6. 展示“质量评估”：说明 FID/SSIM/PSNR 用于回答“生成图像像不像真实图像”。
7. 展示“样本筛选/后处理”：说明清晰度、灰度方差、亮度阈值用于减少低质量样本进入下游训练。
8. 展示“下游分类验证”：说明它回答“生成样本有没有用”，支持早停、类别损失权重、ResNet18/MobileNet 对比和低置信度样本导出。
9. 展示“目标检测验证”：说明系统已能读取 VOC XML 标注并训练 Faster R-CNN MobileNet-FPN；由于 GAN ROI 样本没有 bbox，检测增强仍作为后续扩展。
10. 展示“工业应用评估”：说明最低类别召回率和代价加权错误率更贴近工业漏检风险。

## 4. 导师可能追问与回答要点

### 为什么 GAN 没有一开始就超过传统增强？

传统增强对 NEU-DET 分类任务非常有效，因为旋转、翻转和亮度扰动直接覆盖了分类器需要的几何与光照变化。早期 GAN 样本质量不稳定，低质量样本会引入噪声。因此本文没有只看“能生成图片”，而是加入质量评估、筛选、比例消融和工业门槛复验。

### 为什么最后选择每类 100 张？

比例消融显示，每类 25、50、100 张对应最佳准确率分别为 97.22%、98.06%、99.72%，最佳损失分别为 0.1259、0.0719、0.0533。说明在 40 轮 cGAN-v2 质量已经改善后，增加到每类 100 张能够继续提供有效纹理变化。

### 工业应用为什么看最低召回率？

工业质检更怕漏检高风险缺陷。总体准确率可能掩盖某一类缺陷召回率不足的问题，因此系统加入最低类别召回率和代价加权错误率。300 张方案的 `pitted-surface` 召回率只有 90.00%，所以不建议直接上线；600 张方案最低类别召回率达到 98.33%，因此通过门槛。

### 结果是否稳定？

600 张方案进行了 3 随机种子复验。增强组平均最佳准确率为 99.44%，基线为 98.15%；增强组平均最佳损失为 0.0647，基线为 0.0941。该结果比单次实验更稳，但后续仍可继续扩展更多随机种子和目标检测 mAP 验证。

### 为什么目标检测验证暂时不直接加入 GAN 样本？

当前 GAN 生成的是按类别组织的 ROI 图像，不包含原图坐标系下的边界框。目标检测训练需要图像和 bbox 成对出现，如果直接把 ROI 当完整检测图加入，会改变任务定义。因此系统先补充原始 XML 标注的检测验证入口，后续可继续做“带 bbox 的传统增强”或“将生成 ROI 贴回原图并生成新标注”。

## 5. 谨慎表述

- 不说“GAN 一定优于传统增强”，而说“在训练充分、筛选和比例合适时，GAN 增强可以达到或超过传统增强的下游分类效果”。
- 不说“已经可无人值守上线”，而说“通过当前设定的工业就绪度门槛，可进入小规模试运行或人工复核并行验证”。
- 不说“FID 越低一定越好”，而说“FID 是分布相似性的参考指标，最终仍以下游验证和工业风险指标共同判断”。

## 6. 最后总结句

本毕业设计的价值不只是实现了一个 cGAN，而是把工业缺陷数据增强做成了可运行、可诊断、可复验、可展示的系统闭环；从导师和工业应用角度看，系统能够解释为什么某个增强方案有效、什么时候不该上线、下一步该优化哪一类缺陷。
